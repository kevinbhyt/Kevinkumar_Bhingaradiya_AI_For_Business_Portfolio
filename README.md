**Reflection**<br>
**What I learned across all modules:** Across seven projects built on Géron's *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* (3rd ed.), I learned the full machine learning workflow, and the biggest lesson was that a model has to be judged by evidence, not by one headline number. In Project 1, tuning a Random Forest pipeline with RandomizedSearchCV cut the error of my California housing price predictions from about $68,600 with Linear Regression to about $42,100. In Project 2, my MNIST 5-detector was right about 96% of the time, yet a dummy model that never predicts a 5 already scores 91%; the confusion matrix showed that it found only 65% of the real 5s, and raising its precision to 90% cut its recall to 48%. Project 3 showed how much data preparation matters: scaling the features lifted a linear SVM on the Wine dataset from 91% to 97.7% accuracy. Project 4 made overfitting concrete: an unrestricted Decision Tree scored 100% on its training data but only 81% on the test set, while a tree limited to 17 leaves reached 86% and a majority vote of 1,000 small trees reached 87%. Project 5 showed that no technique is a rule: PCA kept 95% of the variance of MNIST with 154 features and made an SGD classifier faster and more accurate, but it made a Random Forest slower and less accurate. Projects 6 and 7 then showed me how Keras and TensorFlow turn these ideas into neural networks for images and text.<br>
**Skills I developed:** For data preprocessing, I explored and prepared real datasets (California housing, MNIST, Wine, the moons dataset and 5,574 SMS messages): I split training and test sets, scaled features with StandardScaler, built preprocessing pipelines, and turned text into numbers through lowercasing, punctuation and stopword removal, tokenization and a 7,695-word Bag-of-Words. For model tuning, I used cross-validation, GridSearchCV and RandomizedSearchCV with linear models, SVMs, Decision Trees and Random Forests; a randomized search over C and gamma gave an RBF-kernel SVM 97.8% accuracy on the Wine test set. For deep learning, I found a learning rate by growing it exponentially until the loss shot up, then trained a 266,610-parameter MLP with early stopping and checkpoints to 97.7% test accuracy on MNIST, and I built a Keras model with an Embedding layer that classified 98.6% of the test SMS messages correctly. For visualization, I used Matplotlib maps and scatter plots, confusion matrices, precision/recall and ROC curves, decision-boundary plots, Graphviz trees and flowcharts, TensorBoard learning curves and t-SNE maps of 5,000 handwritten digits. I also learned to debug notebooks methodically, tracing each error to its cause and documenting the fix.<br>
**How these projects prepare me for real-world ML tasks:** These projects mirror the decisions a machine learning engineer makes on real business problems. Because data such as fraud, churn or spam is usually imbalanced, I now choose precision, recall and F1 according to the business cost of each kind of error; in my spam filter, only 2 of 966 legitimate messages were flagged as spam while 135 of 149 spam messages were caught, which tells users far more than the 98.6% headline accuracy. I know to keep the test set untouched until the end, to compare every model with a simple baseline, to treat preprocessing and dimensionality reduction as choices to test, and to measure overfitting instead of discovering it in production. Project 7 took me through a complete pipeline, from raw text to a trained model, an evaluation, a flowchart of the process and an interface where a user can classify a new message, which is the same shape as a text classification service in production. Combined with my experience as a software engineer, these skills prepare me to turn models into reliable, explainable features that a business can trust.<br>
